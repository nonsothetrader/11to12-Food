# 11 to 12 - Branding & Project Overview

This is the "11 to 12" food subscription service, specifically engineered for the Lagos office warrior.

## 🎨 Branding Guidelines

### Visual Identity
- **Primary Color**: Vibrant Orange (`hsl(25 95% 53%)`) - Energy, Speed, Appetite.
- **Background**: Warm Cream (`hsl(30 56% 95%)`) - Comfort and Clarity.
- **Typography**: 
  - **Headlines**: *Shrikhand* (Playful, Bold, Relatable).
  - **Body**: *Inter* (Clean, Professional).

### Brand Voice: "The Playfully Savage Colleague"
- **Tone**: Transparent, empathetic to the office grind, and slightly sarcastic.
- **Mission**: To provide lunch that is "Actually Good" and "On Time" without the corporate fluff.

## 🚀 Key Features
- **Justice Dashboard**: Full admin control over kitchen ops, orders, and global announcements.
- **Subscriber Command Center**: Time-adaptive UI that shifts from "Meal Selection" to "Live Tracking" to "Countdown."
- **Pricing Engine**: A granular, custom plan builder with live-updating math and upsell logic.
- **AI Integration**: Genkit-powered witty confirmations that engage users with Lagos-themed humor.

## 🛠 Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS + Shadcn UI
- **Backend**: Firebase (Auth, Firestore)
- **AI**: Genkit (Google Gemini)
